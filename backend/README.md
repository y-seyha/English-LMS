# EnglishEase — Backend

NestJS API for the [EnglishEase English learning platform](https://github.com/y-seyha/English-LMS) — grammar lessons, stories, vocabulary, progress tracking, spaced-repetition review, and leaderboards with Khmer translations.

See the [root README](../README.md) for setup, environment variables, seeding, and deployment instructions.

## Quick start

```bash
npm install
npm run seed   # seed MongoDB with starter content
npm run start:dev
```

Swagger API docs: `http://localhost:4000/docs`
